# riakhin-card

Шаблон одностраничной визитки для Cloudflare Pages.

Для нового человека достаточно заменить `site-config.json` и `portrait.jpeg`.
В `site-config.json` меняются имя, текст, ссылки, номер и список соцсетей.

Для публикации: подключить этот репозиторий в Cloudflare Pages как Static HTML,
без команды сборки и без папки вывода.


## Share + QR test

Isolated prototype based on Personal Card Template v1.0 (`b574c163160e35966a821a74598a2e503abab0a7`). The QR code intentionally points to the production public card URL, not this test deployment.
